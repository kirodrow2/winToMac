# winToMac

**Сайт и скачивание:** https://kirodrow2.github.io/winToMac/ · [последняя версия (ZIP)](https://github.com/kirodrow2/winToMac/releases/latest/download/winToMac.zip)

Оболочка для Windows в стиле macOS: верхняя строка меню и нижний док. Работает только на основном мониторе.

## Запуск

`winToMac.exe` — один файл, .NET ставить не нужно. Выход: значок ⊞ слева вверху → «Выйти из winToMac».
При выходе (и при падении) панель задач Windows возвращается.

Обновление: положите новый exe рядом со старым под другим именем (например, `winToMac.update.exe`) и запустите —
она сама закроет работающую копию, встанет на место `winToMac.exe` и удалит лишние файлы.

## Что умеет

**Верхняя панель**
- ⊞ — системное меню: «Об этом компьютере», параметры, все приложения, свернуть все окна, сон / перезагрузка / выключение, блокировка, выход.
- Жирным — название активного приложения (клик: свернуть / закрыть окно).
- Значки фоновых программ (трей) — клики уходят самой программе, как в панели задач Windows.
- Раскладка — меню со списком раскладок; батарея — заряд и время работы; Wi‑Fi — список сетей,
  подключение к сохранённым; громкость — ползунок (колесо мыши — ±2%); часы — календарь и уведомления.

Окна не заходят под верхнюю панель и док. Обе панели прячутся, только когда активно полноэкранное
приложение (игра, видео на весь экран).

**Док**
- Первый значок — «Все приложения» (список с поиском и избранным).
- Закреплённые приложения, затем запущенные незакреплённые, «Свернуть все окна», корзина.
- Клик: запустить → вывести окно → свернуть, если оно уже активно; если окон несколько — листать их.
- Правый клик по значку: список окон, новое окно, сдвинуть, закрепить/убрать, закрыть.
- Правый клик по фону дока: увеличение, автоскрытие, настройки.
- Можно перетащить на док `.exe` или ярлык — он закрепится.

**Все приложения** — все программы из меню «Пуск». ☆ добавляет в избранное, избранное = закреплено в доке.
Enter открывает первое найденное, Esc закрывает.

**Клавиатура как на Mac** (замена Kinto и PowerToys — их нужно выключить):
- ⌘ = Alt на клавиатуре ПК, ⌘ = Win при подключении с Mac через Moonlight/Sunshine.
  Источник определяется на каждом нажатии: Sunshine вводит клавиши программно, и Windows это помечает.
- ⌘C/V/X/Z/A/S/F/T/W… — как Ctrl; ⌘⇧Z — повторить; ⌘Q — закрыть; ⌘H/⌘M — свернуть; ⌘Tab — переключение;
  ⌘Пробел — поиск приложений; ⌘←/→/↑/↓ — к краям строки/документа; ⌘⌫ — удалить до начала строки;
  ⌥←/→, ⌥⌫ — по словам; ⌘⇧3/⌘⇧4 — снимки экрана; ⌘⌥Esc — диспетчер задач; ⌃⌘Q — блокировка.
- Клавиша смены языка — Caps Lock или то, во что он переназначен в реестре (например, F13; определяется сам),
  либо любая записанная. Удержание — обычный Caps Lock. Способ смены: Win+Пробел, своё сочетание (Alt+Shift…) или «тихо».
- Свои переназначения, как в PowerToys: «нажал → получил» (сочетание или действие), можно только для одной программы.
- В полноэкранных играх и в программах из списка исключений клавиши не трогаются.
- В окнах, запущенных от администратора, переназначение не работает, если сам winToMac запущен без прав администратора.

**Живые обои** (⊞ → «Живые обои…»): встраиваются под значки рабочего стола.
- Анимированные: Sonoma, Ventura, Monterey, Big Sur (в стиле macOS), Bloom, Glow (в стиле Windows 11), Полярное сияние, Закат —
  рисуются самим приложением, скачивать ничего не нужно.
- Свои видео (MP4, MOV, WMV, WebM…) и GIF крутятся по кругу. Папка обоев: `Видео\winToMac Wallpapers`.
- Заставки Apple Aerial скачиваются по кнопке с серверов Apple (1080p H.264).
- Пауза, когда рабочий стол закрыт развёрнутым окном или идёт игра.

**Настройки** (⊞ → «Настройки winToMac…») применяются сразу: размер иконок, увеличение, прозрачность,
автоскрытие, высота и шрифт верхней панели, размытие, тема, скрытие панели задач Windows, автозапуск.
Хранятся в `%APPDATA%\winToMac\settings.json`.

## Если панель задач Windows не вернулась

Запустить winToMac и выйти через меню, либо перезапустить проводник:

```
taskkill /f /im explorer.exe && start explorer.exe
```

Если панель задач стала автоскрываемой — «Параметры → Персонализация → Панель задач → Автоматически скрывать».

## Сборка

Нужен .NET 8 SDK:

```
dotnet publish -c Release -r win-x64 --self-contained true -p:PublishSingleFile=true -p:IncludeNativeLibrariesForSelfExtract=true -p:EnableCompressionInSingleFile=true -p:DebugType=none -o publish
```

## Структура

- `Native/` — Win32: резервирование места (AppBar), скрытие панели задач, окна, иконки, громкость, размытие.
- `Services/AppCatalog.cs` — список всех приложений (`shell:AppsFolder`) и запуск.
- `Settings/AppSettings.cs` — настройки и закреплённые приложения.
- `UI/` — верхняя панель, док, список приложений, настройки, меню и тема.

## Выпуск

`./build-release.sh` (нужны .NET 8 SDK и Python 3) собирает `release/winToMac/` — в корне `winToMac.exe`,
рядом `Instructions/` (инструкция на 10 языках, генерируется `Docs/instructions.py`) и `Licenses/` — и архив
`release/winToMac-<версия>.zip`. Версия — `<Version>` в `winToMac.csproj`.

Ссылки на донаты и сайт — `Settings/ProjectLinks.cs`; пустые пункты в программе не показываются.
При первом запуске под новым именем настройки, папка обоев и автозапуск переносятся со старого имени MacShell.

## Перевод интерфейса

Тексты в коде пишутся по-русски внутри `L.T("…")` — русский текст и есть ключ. Переводы: `Localization/translations_*.py`
(по одной строке на ключ, в порядке `Localization/keys.json`), сборка JSON — `python3 Localization/build_translations.py Localization/keys.json`
(проверяет число строк, подстановки `{0}` и переводы строк). Новый текст в коде → добавить ключ в `keys.json` и строки во все языки.
